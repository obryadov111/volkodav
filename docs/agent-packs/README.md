# Паки платформ и агент: документация

Документы описывают подсистему контент-паков — как агент собирает данные с разного оборудования
(международного и российского), не требуя релиза при добавлении платформы. Код лежит рядом:
`agent/` (движок проб), `src/backend/app/services/packs/` (формат, подпись, оценка),
`src/backend/app/packs/` (каталог паков).
