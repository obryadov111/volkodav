# Паки платформ и агент: документация

Документы описывают подсистему контент-паков — как агент собирает данные с разного оборудования
(международного и российского), не требуя релиза при добавлении платформы. Код лежит рядом:
`agent/` (движок проб), `src/backend/app/services/packs/` (формат, подпись, оценка),
`src/backend/app/packs/` (каталог паков).

| Документ | О чём |
|---|---|
| [stage0-report.md](stage0-report.md) | **Подробный отчёт по этапу 0**: что сделано, как устроено, как проверено, ограничения, развёртывание |
| [architecture.md](architecture.md) | Архитектурное обоснование: контент-паки, декларативные пробы, мультиклиентность, версии, покрытие; словарь терминов |
| [platforms.md](platforms.md) | Каталог оборудования (международное и российское), почему нет универсальных ключей, чек-лист добавления платформы |
| [roadmap.md](roadmap.md) | Пять этапов плана и статус |

Тексты изначально велись в Obsidian-vault `obsidian_hardening` (`05-agents/`); здесь они лежат рядом с кодом
и версионируются вместе с ним. Ссылки на заметки, которых нет в этом репозитории, помечены как заметки vault.
