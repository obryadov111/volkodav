# 🛡️ Yakilka — система автоматизации харденинга ИТ-инфраструктуры

## 📌 Описание проекта

**Yakilka** — это система для автоматизированного сбора, анализа и контроля соответствия конфигураций ИТ-инфраструктуры требованиям информационной безопасности (харденинга).

Система предназначена для:

* проведения аудита ИБ
* выявления отклонений от стандартов безопасности
* формирования рекомендаций по настройке систем

> ⚠️ В отличие от сканеров уязвимостей, система не ищет уязвимости,
> а анализирует корректность настроек и соответствие политикам безопасности.

---

## 🎯 Цель проекта

Разработка системы, позволяющей:

* централизованно собирать конфигурации ПО и СЗИ
* сравнивать их с эталонными требованиями (политиками)
* выявлять отклонения (non-compliance)
* визуализировать результаты аудита
* формировать отчёты для заказчиков

---

## 🧠 Принцип работы

Система реализует следующий процесс:

```text
Агент → Сбор данных → База данных → Анализ → UI
```

### 🔹 1. Сбор данных

Агенты, установленные в инфраструктуре:

* собирают информацию о ПО
* собирают конфигурации
* определяют используемые СЗИ

### 🔹 2. Хранение

Данные отправляются в централизованную БД:

* конфигурации
* инфраструктура
* политики безопасности

### 🔹 3. Анализ (харденинг)

Система выполняет сравнение:

```text
Текущее состояние ≠ Требуемое состояние
```

Результат:

* ✔ соответствует требованиям
* ✖ требует настройки
