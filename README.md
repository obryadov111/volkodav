# Система аудита ИТ-инфраструктуры

## 📌 Описание проекта

Данный проект представляет собой систему автоматизированного сбора и анализа информации о состоянии ИТ-инфраструктуры организаций.

Система позволяет:

* собирать данные с рабочих станций и серверов
* анализировать соответствие требованиям безопасности
* выявлять нарушения (уязвимости)
* визуализировать результаты через веб-интерфейс

---

## 🧱 Архитектура системы

Система состоит из следующих компонентов:

### 1. Агент

Устанавливается на устройства (ПК/серверы) и выполняет:

* сбор информации о системе
* сбор списка установленного ПО
* сбор данных о средствах защиты
* отправку данных на сервер через API

---

### 2. Backend (API)

Серверная часть системы:

* принимает данные от агентов
* сохраняет их в базу данных
* выполняет анализ (проверка правил безопасности)
* предоставляет API для веб-интерфейса

---

### 3. База данных

Хранит:

* организации
* устройства
* результаты сканирования
* правила безопасности
* нарушения

---

### 4. Веб-интерфейс (Frontend)

Позволяет пользователю:

* просматривать устройства
* анализировать состояние системы
* выявлять нарушения
* работать с правилами

---

## 🔐 Мультиарендность

Система поддерживает работу с несколькими организациями:

* каждая организация имеет свой API-ключ
* данные полностью изолированы
* пользователи видят только свою организацию

---

## 🔄 Поток данных

1. Агент собирает данные на устройстве
2. Отправляет их на сервер через API
3. Backend обрабатывает данные и сохраняет их
4. Выполняется проверка правил безопасности
5. Результаты отображаются пользователю через веб-интерфейс

---

## 📊 Основной функционал

* Dashboard (сводка по системе)
* Список устройств
* Детали устройства
* Список нарушений
* Список правил безопасности

---

## 🛠️ Используемые технологии

* Backend: Python (FastAPI)
* Frontend: HTML, CSS, JavaScript
* База данных: PostgreSQL

* система уведомлений
